# Yoyo 的個人作品集

徐天祐的個人作品集，展示個人背景、技能、學經歷與專案成果。

網站以卡片呈現內容，支援作品詳細介紹、響應式版面、深淺主題與互動動畫。
使用 React、TypeScript、Vite、CSS Modules 與 GSAP 開發。

[瀏覽作品集](https://Yoyo8787.github.io/Yoyo-s-Portfolio/)

## 安裝與啟動

需使用 Node.js 20.19 以上（20.x），或 22.12 以上。

安裝依賴：

```sh
npm install
```

啟動開發伺服器：

```sh
npm run dev
```

啟動後開啟終端機顯示的網址即可瀏覽。
